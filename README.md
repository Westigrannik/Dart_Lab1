15. Ответы на вопросы

Q 1. Чем статическая типизация Dart отличается от Python? Какое практическое
преимущество она даёт?
A 1. Тем, что она известна на этапе компиляции

Q 2. Что означает String?? Чем отличается от String?
A 2. Если string имеет ??, то оно null по умолчанию, а если ?, то по условию

Q 3. Зачем в Dart final, если в Python можно просто договориться не менять переменную?
A 3. Для того, что он может быть полезен тем, что он выполняет во время выполнения задачи

Q 4. Чем именованный параметр {required String name} отличается от позиционного? Приведите пример вызова.
A 4. Он отличается в том, что этот параметр обязателен, ведь Flutter использует именованные параметры, а без этого Flutter не сможет их прочитать. Допустим вы вызываем параметр, а код его не находит и просто даёт ошибку.
